Что такое Git

Git — это машина времени для папки с проектом.

Он запоминает снимки состояния, а не «разницу» между файлами.

стол → коробка → склад

Основной цикл

проверь git status
подготовь git add
сохрани git commit -m "..."
отправь git push

Коммит

Коммит = снимок + сообщение + автор + время

Плохо «fix»
Хорошо «добавил вывод массива в консоль»

Ветки и слияние

Ветка — параллельная версия проекта.

Слияние возвращает изменения в основную ветку.

Git ≠ GitHub

Git

Программа-дневник на вашем компьютере.

GitHub / GitLab

Сайт, где дневник лежит в облаке.

Мини-демо

01 git init создаёт репозиторий в папке проекта
02 git status показывает, какие файлы изменились
03 git add . отправляет изменения в Staging
04 git commit -m "..." сохраняет снимок состояния с описанием
05 git log --oneline показывает историю коммитов списком
